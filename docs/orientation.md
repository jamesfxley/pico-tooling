# Orientation

Start at the [root instructions](../AGENTS.md). Edit `pico_tooling/`, `cmake/`
and `guides/`; House and standard changes belong in their own repositories.
Run checks against the final indexed state.

Generated library output is owned here and checked in each library. A change
to a renderer changes every library's expected files, so prepare one reviewed
batch of library updates without editing generated files by hand.
